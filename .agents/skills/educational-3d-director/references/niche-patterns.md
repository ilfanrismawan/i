# Cross-niche mechanism patterns

| Niche | Familiar action | Hidden mechanism | Asset phases | Signature animation |
|---|---|---|---|---|
| Consumer electronics | touch, unlock, charge | electrodes, optics, signals | exterior → cutaway → component → signal → UI | macro flythrough + local highlight |
| Construction | water drains, tiles adhere | layers, gradients, curing | environment → cross-section → material → sequence | layer separation + flow |
| Biology | breathing, heartbeat | tissue, pressure, circulation | anatomy → cutaway → moving anatomy → flow | transparent overlay + rhythmic motion |
| Food science | baking, boiling, refrigeration | heat/phase change | appliance → material → heat/particles | thermal cutaway |
| Automotive | braking, steering | hydraulics, friction, sensors | vehicle → assemblies → physical response | exploded mechanical interaction |
| Space/physics | launch, eclipses, orbit | force and geometry | celestial/vehicle → scale model → vectors | physically labeled trajectory |
| Agriculture | watering, growth | soil/capillarity/plant anatomy | field → soil cross-section → growth stages | time-lapse scientific zoom |
| Fashion/textiles | water repellency, fabric stretch | fibers, weaving, chemistry | garment → weave macro → response | fiber cutaway + deformation |
| Product manufacturing | glass, chips, batteries | industrial process | input material → station assets → assembly | process line + assembly choreography |
| Historical reconstructions | building, route, artifact | contextual process | site → reconstructed environment → sequence | before/after with uncertainty labels |

Never use a universal fixed stage count; generate only relevant phases. Example: a kitchen science explainer doesn't need touchscreen sensor nodes or an application UI. Provide consistent stages for audience comprehension and project reuse.
