# Narrative modes across niches

## Mechanism reveal
Familiar behavior → curiosity question → cutaway → cause/effect → concrete outcome. Applies to electronics, vehicles, biology, architecture.

## Surprising fact
A specific, sourced counterintuitive observation → show what viewers expect → reveal evidence and mechanism → explain important exception → memorable conclusion. Do not overstate prevalence or certainty.

## Manufacturing process
Finished object → raw materials → ordered factory operations → quality check → final object. Differentiate generalized process from exact confidential production methods.

## Reconstruction
Observed object/event → verified records → evidence limits → hypothetical assembly tagged as reconstruction → constrained conclusion. Useful for history and ancient technology.

## Invisible scale
Everyday object → microscope/cutaway → scale anchor → underlying particles/cells/material structure → result. Label scale exaggerations and simulated representation.

## Investigation / debunk
Claim people encounter → testable prediction → documented evidence → qualified conclusion. Avoid constructing a straw-man myth for engagement.

## Scoring rubric
Score curiosity, familiarity, visualizability, learning value, differentiation, feasibility (1–5). Verification is a separate prerequisite: unverified facts are NOT production-ready, regardless of rank.

## Script style
Indonesian conversational narration by default; no fake "real case" or fabricated person; no CTA if user prefers explanatory ending. Short sentences synchronized to visual changes. Use one clear reveal per segment.
